📦 方案A：GitHub Pages（推荐）

步骤1：初始化Git仓库
─────────────────────
在当前文件夹打开命令行/PowerShell，运行：

  git init
  git add .
  git commit -m "Initial commit: Biology study guide"

或者双击运行：创建Git仓库.bat


步骤2：创建GitHub仓库
─────────────────────
1. 打开 https://github.com
2. 登录账号（没有的话先注册，免费）
3. 点击右上角 "+" → "New repository"
4. 仓库名称：biology-notes（或你喜欢的名字）
5. 描述：Biology Study Guide - 生物学习笔记
6. 选择 Public（公开，这样才能用GitHub Pages）
7. 不要勾选任何初始化选项
8. 点击 "Create repository"


步骤3：连接并推送
─────────────────
GitHub会显示一些命令，复制运行（替换YOUR-USERNAME和REPO-NAME）：

  git remote add origin https://github.com/YOUR-USERNAME/biology-notes.git
  git branch -M main
  git push -u origin main

输入GitHub用户名和密码（或token）


步骤4：启用GitHub Pages
───────────────────────
1. 在GitHub仓库页面，点击 "Settings"
2. 左侧菜单找到 "Pages"
3. Source: 选择 "Deploy from a branch"
4. Branch: 选择 "main" 和 "/ (root)"
5. 点击 "Save"
6. 等待1-2分钟


步骤5：访问你的网站
───────────────────
网址格式：
https://YOUR-USERNAME.github.io/biology-notes/website/

注意：需要加 /website/ 才能看到网站！

或者将website文件夹的内容移到根目录更简洁。

🎯 方案B：Netlify（最简单！）

步骤1：去Netlify
────────────────
打开 https://www.netlify.com
点击 "Sign up" 注册（可用GitHub账号登录）


步骤2：部署网站
────────────────
1. 点击 "Add new site" → "Deploy manually"
2. 把 deploy_package 文件夹直接拖进去
3. 等待30秒
4. 完成！


步骤3：获取网址
────────────────
Netlify会自动生成一个网址，类似：
https://biology-notes-abc123.netlify.app

可以在设置里自定义域名的前半部分。


优点：
✓ 最简单，拖拽即可
✓ 自动HTTPS
✓ 全球CDN加速
✓ 每次更新只需重新拖拽

⚡ 方案C：Vercel

步骤1：去Vercel
───────────────
打开 https://vercel.com
注册账号（建议用GitHub登录）


步骤2：导入项目
────────────────
1. 点击 "Add New" → "Project"
2. 选择 "Import Git Repository"
3. 如果用了GitHub，直接导入
4. 或者选择 "Deploy" 拖拽文件夹


步骤3：配置
───────────
Framework Preset: Other
Root Directory: ./deploy_package
点击 "Deploy"


步骤4：访问
───────────
网址类似：https://biology-notes.vercel.app

优点：
✓ 速度快
✓ 专业
✓ 自动部署
✓ 免费
